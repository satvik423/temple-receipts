# Temple Receipts App — Feature List & Pricing

A custom receipt/billing system built for the temple, covering sales (Sevas), donations (Kanike),
printing (browser + USB thermal), reporting, and multi-user admin.

## Features Delivered

| Feature | What it does |
|---|---|
| **Sell (POS) flow** | Searchable seva catalog, cart, custom-amount items with bhakta name/phone, checkout, automatic GBN/DBN receipt numbering |
| **Kanike (donation) flow** | Dedicated donation entry form, edit, reprint, filtered by date |
| **Kanike A5 voucher** | Custom-designed printable voucher matching the temple's own paper template, with optional bhakta address and amount-in-words |
| **Receipt printing** | Browser print + USB thermal printer (ESC/POS) integration with automatic fallback if no printer is connected; "COPY" watermark on reprints |
| **UPI QR on receipts** | Auto-generates a QR code pre-filled with the exact receipt amount, using a UPI ID set once in Settings; hidden entirely if not configured |
| **Temple branding** | Logo on printed vouchers, custom app icons/favicon |
| **History** | Browse and reprint any past receipt, filterable by date, running totals |
| **Analytics dashboard** | Revenue over time (daily/weekly/monthly), breakdown by seva type — admin only |
| **Reports** | Downloadable PDF and Excel reports — itemized bill report and day-summary report, by date range |
| **Sevas management** | Add/edit/reorder/activate sevas and kanike types, fixed or custom pricing |
| **Settings** | Temple name/place/phone header (used across all prints), UPI ID, Grand Bill Number sequence override, printer connect |
| **Multi-user accounts & roles** | Admin vs staff roles, user management, secure bcrypt-hashed login, forgot/reset password by email, first-time setup |
| **Bilingual Kannada + English** | Proper Kannada font rendering, consistent bold typography across every device and print output |
| **Mobile + desktop responsive** | Works as an installable app on phone or laptop |
